# Muhammad Javid Pasha – Portfolio

Personal developer portfolio, redesigned around a "code editor / file system"
visual identity — sections read like files (`about.md`, `skills.json`,
`education.log`, `contact.sh`), education is shown as a git commit log, and
projects are split into featured builds and an archive listing.

Built with:
- ⚛️ React (Vite)
- 🎨 Tailwind CSS
- 🎞 Framer Motion
- 🔗 React Router

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Features
- Distinctive editor/file-system inspired design system
- Featured projects + project archive with detail pages
- Education shown as a chronological commit log
- Fully responsive, keyboard-focus visible, respects reduced motion
